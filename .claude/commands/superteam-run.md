# Usage: /superteam-run

Take the Orchestrator role and drive an already-initialized SuperTeam campaign —
pack the next wave and begin dispatching. Not for creating a campaign (that's
`/superteam`).

<instructions>
Read the canonical run skill in this repository and execute it in full:

    skills/superteam-run/SKILL.md      (relative to this repo's root)

It tells you how to read the campaign's truth from disk, pack and prepare one
wave, run it (interactively as the Wave General, or detached via the guarded
launcher), and close it only after an independent cold audit PASS.

If there is more than one initialized campaign, ask which workspace before
touching anything.
</instructions>
